# UniConv — конвертер инженерных единиц

UniConv переводит значения между единицами одной физической величины. В поставку входят 48 величин, четыре температурные шкалы, таблица твёрдости и три пресета единиц. Библиотека работает на Python 3.7+ без зависимостей времени выполнения.

```console
python -m pip install "uniconv==2.0.0"
```

```python
from uniconv import UnitConverter

converter = UnitConverter()
assert converter.convert(10, "бар", "МПа", type_id="0") == 1.0
assert converter.convert(212, "F", "C", type_id="1") == 100.0
```

`type_id` — строковый ID величины. Коды единиц берите из справочника или из поля `code` метода `get_available_units()`. Поле `ui` предназначено для отображения: например, код `кгс/см2` и подпись `кгс/см²`.
