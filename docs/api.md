# Публичный API

[Все разделы](README.md) · [Коды единиц](units.md)

Импорты из `uniconv`: `UnitConverter`, `UnknownParameterError`, `UnknownUnitError`, `DataLoadError`, `constants`. Ниже `Number` означает `int` или `float`.

## Конвертация и метаданные

| Метод | Результат |
|---|---|
| `UnitConverter()` | Новый независимый экземпляр, загружает ресурсы из пакета. |
| `convert(value, from_u, to_u, type_id)` | Число в целевой единице или `None`, если для твёрдости нет результата. После проверки кодов при совпадении единиц возвращает исходное значение. |
| `to_base(value, from_u, type_id)` | Преобразование в базовую единицу величины. |
| `from_base(value, to_u, type_id)` | Преобразование из базовой единицы. |
| `get_base_unit(type_id)` | Код базовой единицы. |
| `get_available_units(type_id)` | Список словарей `{"code": ..., "ui": ...}` в порядке реестра. |
| `get_parameter_info(type_id)` | Словарь с ключами `id`, `name_RU`, `name_ENG`, `base_unit`. |

Все аргументы конвертации можно передавать по имени. Методы перехода в базовую единицу и обратно тоже могут вернуть `None` для неподдерживаемого табличного значения.

Линейная конвертация считает `value × factor_from / factor_to`, где каждый коэффициент переводит единицу в базовую. Базовая единица выбирается отдельно для каждой величины и может отличаться от СИ. Температура проходит через Celsius (`C`), твёрдость — через Brinell (`HB`). Библиотека не проверяет физическую допустимость числа, например температуру ниже абсолютного нуля.

## Пресеты

| Метод | Результат |
|---|---|
| `list_presets()` | Имена пресетов: `SI`, `TECH`, `IMPERIAL`. |
| `get_preset(name)` | Копия исходного словаря ID → код или `None` для неизвестного имени. |
| `apply_preset(name)` | Словарь ID → `{"code": ..., "ui": ...}` после проверки пар или `None` для неизвестного имени. |

Пресеты не меняют значение, базовую единицу или состояние конвертера. Невалидные пары пропускаются с предупреждением логгера `uniconv.converter`. Если у выбранной величины нет пары, используйте свою политику отображения, например базовую единицу.

## Расширение экземпляра

- `add_parameter(type_id, *, base_unit_symbol, base_unit_name, parameter_name, parameter_name_eng=None)` создаёт новую величину. ID — свободная строка из десятичных цифр ASCII; английское имя по умолчанию совпадает с `parameter_name`.
- `add_unit(type_id, *, unit_symbol, unit_name, to_base, from_base=None, display_label=None)` добавляет единицу. Числовой `to_base` — конечный ненулевой множитель в базовую единицу; при отсутствии `from_base` используется обратный пересчёт. Для функции `to_base` значение `from_base` обязательно. Явный числовой `from_base` — множитель из базовой единицы; вместо него можно указать функцию. UI-метка по умолчанию равна коду.

Методы возвращают `None` и меняют только этот экземпляр. Базовую единицу нельзя переопределить. Если передать код уже существующей небазовой единицы, её преобразование и метка будут заменены в этом экземпляре. Аргументы `base_unit_name` и `unit_name` сохранены в сигнатурах; интерфейс отображения использует код или `display_label`.

## Ошибки и отсутствие результата

| Сигнал | Когда возникает |
|---|---|
| `UnknownParameterError` | Неизвестный или неверно переданный ID при обращении к величине. |
| `UnknownUnitError` | Исходный либо целевой код не зарегистрирован у выбранной величины. |
| `DataLoadError` | Отсутствующий, невалидный или повреждённый ресурс пакета, в том числе ошибочная ссылка на константу. |
| `ValueError` | Некорректное расширение: например, повтор ID, замена базовой единицы или отсутствующий обратный пересчёт для функции. |
| `None` | Неизвестный пресет или отсутствие результата табличной конвертации; это зависит от вызванного метода. |

Три именованных исключения наследуются от `ValueError`. Модуль `uniconv.constants` содержит именованные физические и математические константы, например `G_STANDARD` и `CELSIUS_TO_KELVIN_OFFSET`.
