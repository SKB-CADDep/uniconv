# Документация UniConv

Если вы подключаете библиотеку впервые, начните с [быстрого старта](getting-started.md). Для работы с конкретной величиной откройте [коды единиц](units.md) и [справочник API](api.md). Готовые решения собраны в [практических сценариях](usage.md) и [запускаемых примерах](../examples/README.md).

Переходите с 1.x? Прочитайте [руководство по миграции](migration.md). [Инженерная спецификация](uniconv.md) хранит исходные требования и таблицы; публичные сигнатуры и фактическое поведение описаны в руководстве и справочнике API.

## Как обновлять документацию

Из корня репозитория выполните:

```console
python tools/generate_units_reference.py
python tools/generate_units_reference.py --check
python -m unittest discover -s tests -v
```

Генератор читает поставляемый JSON-реестр и строит страницу `units.md`. Правьте реестр, а затем обновляйте страницу через генератор. Справочник приводит точные коды и UI-метки; правила конвертации описаны отдельно.

Проверки запускают Python-примеры из руководства и самостоятельные скрипты. При изменении публичного API обновляйте [справочник](api.md), сценарии и примеры в той же ветке.
